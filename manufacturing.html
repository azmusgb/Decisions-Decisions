MANUFACTURING PARTNERS

VALIDATE THE BUILD BEFORE THE TOOLING.

GET THE POINT is not yet at final production specification. We are looking for credible supplier input on cards, packaging, drawing components, finishing, MOQ, assembly, freight, and fulfillment before expensive decisions are locked.

CURRENT RFQ DIRECTION

DEVELOPMENT TARGETS, NOT FINAL DIELINES.

The current physical prototype is intentionally compact. Final dimensions, materials, coatings, inserts, and assembly methods remain NEEDS SUPPLIER VALIDATION.

CARD SYSTEM

~100 double-sided cards.

About 200 prompt slots target. Poker-card dimensions are proposed, not supplier-locked. We need realistic stock, finish, print, collation, corner, and durability options.

DRAWING COMPONENT

Reusable and compact.

Dry-erase board/surface plus marker. Material, coating, cleaning behavior, marker retention, and packing method remain open to supplier input.

PACKAGING

Giftable without wasted volume.

Compact box, fast shelf communication, simple component management. Final box structure, insert/no-insert, finishes, and case pack remain open.

COST MODEL INPUTS

WE NEED LANDED-COST TRUTH.

A factory unit price alone is not enough. Useful supplier conversations need to expose the full path from component cost to finished, packed, freight-ready product.

1BOM

Cards, board, marker, box, insert, print, finishing.

2MOQ

Prototype, 500, 1k, 2.5k, 5k, 10k volume behavior.

3LEAD TIME

Proofing, production, assembly, QC, packing.

4LOGISTICS

Cartons, freight, duty, storage, fulfillment assumptions.

SUPPLIER INQUIRY

CAN YOU HELP US COST IT CORRECTLY?

We want transparent, decision-useful information—not pressure to freeze premature tooling.

Most useful now: prototype capability, typical MOQ, comparable game experience, card/box/dry-erase capabilities, finishing options, freight support, and realistic lead times.
