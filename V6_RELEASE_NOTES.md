# GET THE POINT PWA v0.5.0 — Performance UX v6

This release makes HUM and MIME first-class post-commit experiences while preserving the single core mechanic.

- Dedicated HUM/SOUND performance surface with animated audio visualization and explicit no-words constraint.
- Dedicated MIME performance surface with kinetic motion treatment and silent-performance constraint.
- DRAW remains a dedicated in-card canvas with undo/clear and equivalent scoring flow.
- All routes use the same lifecycle: choose → commit → perform → correct → next.
- Ordinary skip moves to pre-commit only in the current test condition.
- Post-commit route switching and pass are removed from the normal player flow.
- No microphone, camera, recording, recognition, or automatic answer checking.
- Updated local-state schema, telemetry export schema, cache generation, and cache-busted assets.

Unresolved rules remain unresolved and require blind-play evidence.
